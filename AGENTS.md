# Contributor Instructions

This repository contains a public Omarchy plugin distribution.

- Keep changes scoped to the plugin and its public documentation.
- Do not commit credentials, tokens, private filesystem paths, session logs, scratchpads, or internal agent instructions.
- Validate `manifest.json` and relevant shell scripts before opening a pull request.
- Include the Omarchy version, display setup, reproduction steps, and relevant logs when reporting a bug.
- Use Conventional Commits when practical and update `CHANGELOG.md` for user-visible changes.
